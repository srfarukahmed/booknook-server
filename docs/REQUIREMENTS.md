- JWT plus live session/account checks; ownership and borrower isolation.
- Server-derived dates and identities; MongoDB timestamps and arrivals sort/limit.
- Transactional copy accounting, duplicate-loan index and last-copy protection.
- Returns restore one copy; copy edits preserve loans; active loans block deletion.
- Updated existing client uses real endpoints, sessions, toasts and image uploads.
- Verification/recovery disabled as requested.
- Random-secret setup, environment template, replica-set Compose service, seed, lockfile, builds and integration tests.
- External OAuth/upload credentials, deployment/live URLs, GitHub repositories and meaningful commit history are not fabricated.
